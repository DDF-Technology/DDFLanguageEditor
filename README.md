# DDFLanguageEditor

Editor WinForms per un linguaggio sperimentale DDF. Il repository include la specifica
sintattica storica in `DDF - Program Language Spec.txt`.

## Stack

- C# e WinForms
- .NET Framework 4.8

## Apertura

Aprire `DDF - Program Language Editor.sln` con Visual Studio 2022.

## Stato

Prototipo di editor: parser, interprete o compilatore completi non sono ancora presenti.
