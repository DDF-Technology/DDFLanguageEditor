# DDFLanguageEditor.Core

Servizi indipendenti dalla UI per pacchetti linguistici DDF, analisi, build,
runtime, debug, flowchart e cataloghi delle API host.

Il pacchetto `DDFLanguageEditor.Core` può essere usato da strumenti senza
WinForms. Per incorporare la superficie grafica o la shell completa usare
`DDFLanguageEditor.WinForms`.

Questa versione è beta e il contratto può ancora evolvere prima della 1.0.
